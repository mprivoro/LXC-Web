Create container

How to choose
  • Cached images (ubuntu / jammy, ubuntu / noble) are already on this host. Pick one and click Create. Nothing is downloaded; LXC uses --force-cache. You do not need a template.
  • Templates are LXC scripts, not those Ubuntu images:
    • download — fetch a new image from the network (set extra options under Advanced).
    • local — your own metadata + rootfs files. This is not the jammy/noble cache.
    • busybox — a tiny busybox container.
    • oci — an OCI/Docker-style image.

Typical case: enter a name, keep a cached image selected, click Create.


*By default it is 'none', which is a simple directory tree under /var/lib/lxc/<name>/rootfs
